# Changelog

All notable changes to Jisr are documented here.

## [Unreleased]

- Prepared public contribution, security, privacy, and support documentation.

## [0.4.2]

- Added verified in-app update downloads with progress.
- Added platform-specific installation handoff for Windows and macOS.

## [0.4.1]

- Adopted the Jisr bridge logo across application assets.

## [0.4.0]

- Renamed OrbitSend to Jisr.
- Moved to the Jisr application identity while retaining legacy update
  compatibility.

## [0.3.1]

- Fixed operating-system drag-and-drop file handling.

## [0.3.0]

- Added public update notifications.

## [0.2.0]

- Added the initial Windows and macOS desktop-sharing application.
